Ira Tracker

Tracks which project you work on, so you don't have to start and stop timers. Check and submit your day at the end.

Download for Mac Download for Windows

1. Get your API token (once)

  1. Create your account at https://__DOMAIN__/register. If it asks you to confirm your email, wait 15 seconds and reload the page (no email is sent). Already have a login from your admin? Sign in instead.
  2. Click your name → Profile → API Tokens → Create API Token, name it "Ira Tracker", and copy it.

2. Install

  1. Mac: open the downloaded file and drag Ira Tracker into Applications, then open it. The first time, macOS says it can't verify the developer: go to System Settings → Privacy & Security and click Open Anyway. This is needed only once.
  2. Windows: run the installer. If SmartScreen appears, click More info → Run anyway.

3. Sign in

  1. Paste your API token and click Sign in. The server address is already filled in.
  2. Read the auto-tracking screen and click I agree, turn on auto-tracking.
  3. Mac: when asked, allow Screen Recording for Ira Tracker, then click Quit & Reopen.

Every day: the tray menu has Review today… to fix projects and times, Pause for private time, and the 18:30 reminder to submit your day.

Privacy

While you track during work hours, a small grayscale screenshot is taken every 5 minutes. It stays on your computer for 3 days so you can check your day, and you can delete any of it. When the window title is not enough, the screenshot is sent to the server only to ask the AI which project it is, and the server does not keep it. Keystrokes, mouse activity, password managers and personal messengers are never captured.
